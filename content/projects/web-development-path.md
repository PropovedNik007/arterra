# Web development path

I have worked across frontend and backend development since 2017, building and
extending production web applications for freelance clients, Linwood, and KRK
Group, and later developing my own Arterra portfolio platform.

## Path

- **Freelance web developer (2017–2018):** delivered frontend and backend work,
  including new applications and extensions to existing systems.
- **Linwood full-stack developer (2018–2019):** developed and tested e-commerce
  applications and expanded business functionality.
- **KRK Group frontend developer (2019):** built React interfaces and API
  integrations for a corporate education platform.
- **Arterra (2024–present):** designed a Svelte portfolio and a publishing
  pipeline that projects approved notes from a private Life OS into a public
  knowledge graph.

## Contribution

Unless a project note says otherwise, the architecture and implementation
