# AIM Hackathon — greenwashing RAG

A platform built during the AIM Hackathon (hosted by TIMETOACT Group, October
2024) that uses Retrieval-Augmented Generation to detect greenwashing in
corporate ESG (Environmental, Social, Governance) reports. It won 2nd place.

## Stack

RAG, LangChain, Flask, OpenAI
